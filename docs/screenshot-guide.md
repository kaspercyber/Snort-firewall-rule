# Screenshot Evidence Guide

Capture genuine screenshots from your own run and add a short caption in the report.

| Filename | Evidence to show |
|---|---|
| `01-virtualbox-network.png` | VM network adapter setting |
| `02-vm-ip-address.png` | Interface/IP output |
| `03-mininet-started.png` | Successful topology startup |
| `04-snort-running.png` | Snort initialisation/running state |
| `05-snort-alert.png` | Relevant alert in the log |
| `06-packet-capture-created.png` | Capture summary and file size, not the PCAP itself |
| `07-iptables-before.png` | Firewall listing before the lab rule |
| `08-iptables-after.png` | Listing showing the rule in FORWARD |
| `09-blocked-test.png` | Actual retest result |
| `10-mininet-cleanup.png` | Mininet exit and cleanup |

Use PNG/JPG, chronological names, readable text, and concise captions. Do not substitute sample output from the handout for your own screenshots. Hide credentials, tokens, public IPs, or personal information when appropriate. Never upload malware samples or raw packet captures.
